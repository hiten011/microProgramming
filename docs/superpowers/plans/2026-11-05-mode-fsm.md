# Mode FSM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `fsm_mode()` that polls PA12 with rising-edge detect, applies MANUAL ↔ AUTO transitions from `docs/mode_fsm.png`, drives mode LEDs, runs after `fsm_tilt()` in the TIM3 tick, and remove EXTI entirely.

**Architecture:** One Mode FSM function mutates `curMode` and LED outputs each 20 ms tick. Button state is polled via `GPIO_InputReadPin(GPIOA, 12)` with a static previous level for edge detection. Axis states `roll` / `pitch` (already updated earlier in the same tick) gate the transitions. Host tests mock the button and LED setters under `#ifdef HOST_TEST`.

**Tech Stack:** C99, STM32C031 GPIO/TIM3, GCC host tests (`-DHOST_TEST`), ARM CMake firmware build

**Spec:** [`docs/superpowers/specs/2026-11-05-mode-fsm-design.md`](../specs/2026-11-05-mode-fsm-design.md)

## Global Constraints

- Transitions: MANUAL → AUTO if `(roll == CLAMPED && pitch == CLAMPED) || rising_edge`; AUTO → MANUAL if `rising_edge && (roll == FREE && pitch == FREE)`.
- LEDs: MANUAL → `set_manual_led(true)`, `set_auto_led(false)`; AUTO → `set_auto_led(true)`, `set_manual_led(false)`.
- Button: once per press via rising edge (`!prev && now`); held high must not retrigger.
- Call order: `fsm_pitch(); fsm_roll(); fsm_tilt(); fsm_mode();`
- Remove `EXTI4_15_IRQHandler` and `EXTI_Init(...)`; keep PA12 input + pull-down.
- Reuse `enum MODE { AUTO, MANUAL }` and `curMode` (initial `MANUAL`). Do not rename to AUTOPILOT.

## File Structure

- Modify: `assignment2/Src/main.c` — add `fsm_mode()`, HOST_TEST guards, TIM3 call, strip EXTI
- Create: `tests/test_mode_fsm.c` — host unit tests for Mode FSM transitions and LEDs

```c
#define HOST_TEST

#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>
#include <math.h>

/* Stubs before including main.c — Angles typedef lives only in main.c under HOST_TEST */
static bool mock_btn;
static bool last_manual_led;
static bool last_auto_led;

void set_manual_led(bool on) { last_manual_led = on; }
void set_auto_led(bool on) { last_auto_led = on; }
void set_roll(uint16_t pulse_us) { (void)pulse_us; }
void set_pitch(uint16_t pulse_us) { (void)pulse_us; }
void set_tilt(uint16_t pulse_us) { (void)pulse_us; }
bool GPIO_InputReadPin(void *port, uint8_t pin) {
    (void)port; (void)pin;
    return mock_btn;
}

#include "../assignment2/Src/main.c"

static void reset_mode(void) {
    curMode = MANUAL;
    pitch = FREE;
    roll = FREE;
    mock_btn = false;
    /* Drain edge state: one call with button low */
    fsm_mode();
    last_manual_led = true;
    last_auto_led = false;
    set_manual_led(true);
    set_auto_led(false);
}

int main(void) {
    /* 1) MANUAL + both CLAMPED → AUTO (no button) */
    reset_mode();
    pitch = CLAMPED;
    roll = CLAMPED;
    mock_btn = false;
    fsm_mode();
    assert(curMode == AUTO);
    assert(last_auto_led == true);
    assert(last_manual_led == false);

    /* 2) MANUAL + rising edge → AUTO */
    reset_mode();
    mock_btn = true;
    fsm_mode();
    assert(curMode == AUTO);

    /* 3) Held button does not re-toggle */
    pitch = FREE;
    roll = FREE;
    mock_btn = true;
    fsm_mode(); /* still held — must stay AUTO, not jump to MANUAL without a new edge after reset */
    assert(curMode == AUTO);

    /* 4) AUTO + rising edge + both FREE → MANUAL */
    reset_mode();
    curMode = AUTO;
    set_auto_led(true);
    set_manual_led(false);
    mock_btn = false;
    fsm_mode(); /* sync prev=low */
    pitch = FREE;
    roll = FREE;
    mock_btn = true;
    fsm_mode();
    assert(curMode == MANUAL);
    assert(last_manual_led == true);
    assert(last_auto_led == false);

    /* 5) AUTO + rising edge + not both FREE → stay AUTO */
    reset_mode();
    curMode = AUTO;
    set_auto_led(true);
    set_manual_led(false);
    mock_btn = false;
    fsm_mode();
    pitch = COMPLIANT;
    roll = FREE;
    mock_btn = true;
    fsm_mode();
    assert(curMode == AUTO);

    printf("test_mode_fsm: all passed\n");
    return 0;
}
```

4. Add `fsm_mode` after `fsm_tilt`:

```c
void fsm_mode(void) {
    static bool prev_btn = false;
    bool now = GPIO_InputReadPin(GPIOA, 12);
    bool rising = (!prev_btn && now);
    prev_btn = now;

    switch (curMode) {
        case MANUAL:
            if ((roll == CLAMPED && pitch == CLAMPED) || rising) {
                curMode = AUTO;
                set_auto_led(true);
                set_manual_led(false);
            } else {
                set_manual_led(true);
                set_auto_led(false);
            }
            break;
        case AUTO:
            if (rising && (roll == FREE && pitch == FREE)) {
                curMode = MANUAL;
                set_manual_led(true);
                set_auto_led(false);
            } else {
                set_auto_led(true);
                set_manual_led(false);
            }
            break;
    }
}
```
